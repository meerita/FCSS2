# FCSS

**Functional CSS** — a framework-agnostic utility CSS library where every class name is a valid CSS property–value pair. If you know CSS, you already know FCSS.

```html
<div class="display--flex align-items--center gap--16 padding--24">
  <p class="color--blue font-size--16 font-weight--bold">Hello, FCSS</p>
</div>
```

## How it works

- **One class, one declaration** — `display--flex` emits exactly `display: flex`. Nothing more.
- **Natural CSS names** — `background-color--blue`, not `bg-blue`. No abbreviations to memorise.
- **Pseudo-states** — `color--red:hover` becomes `.color--red\:hover:hover { color: red }`.
- **ARIA states** — `display--block:aria-expanded:true` becomes `[aria-expanded='true'] { display: block }`.
- **Responsive** — `md-display--none` hides an element above the `md` breakpoint (`min-width: 768px`).
- **Full-set-plus-purge** — ship the complete library; purge unused classes at build time with PostCSS.
- **Zero runtime** — pure CSS in the browser. No JavaScript required.

## Breakpoints

| Prefix | Min-width |
| ------ | --------- |
| `sm`   | 576 px    |
| `md`   | 768 px    |
| `lg`   | 992 px    |
| `xl`   | 1200 px   |
| `xxl`  | 1400 px   |

Mobile-first `min-width` strategy throughout.

## Installation

```sh
npm install @fcss/core
```

Then import the full library and add the purge plugin to your build:

```js
// vite.config.ts
import { fcss } from '@fcss/vite';

export default {
  plugins: [fcss()],
};
```

Or with Next.js:

```js
// next.config.js
const { withFcss } = require('@fcss/next');
module.exports = withFcss({});
```

## CLI

```sh
npx fcss init        # generate fcss.config.ts in your project
npx fcss build       # emit the full CSS library to disk
npx fcss purge       # purge unused classes from a CSS file
npx fcss audit       # report classes used in source that are not in the library
npx fcss list        # list all available utility classes
npx fcss explain     # explain what a class name compiles to
```

## Custom classes

Project-specific multi-declaration rules use the `c-` prefix and live in your own CSS:

```css
/* These are yours — not generated by FCSS */
.c-card {
  display: flex;
  flex-direction: column;
  border-radius: 8px;
  padding: 16px;
}
```
