# @functionalcss/spec

The machine-readable FCSS specification: property and value catalogs, pseudo-class and ARIA
states, breakpoints, and the type contracts shared by the generator and tooling.

Most projects don't need this package directly — install `@functionalcss/core` for the CSS.

## Installation

```bash
npm install @functionalcss/spec
```

## Usage

```ts
import { FCSS_BREAKPOINTS, FCSS_PSEUDO_CLASSES, FCSS_ARIA_STATES } from '@functionalcss/spec';
```
